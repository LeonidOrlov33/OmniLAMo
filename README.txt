Файлы для виртуального ёжика OmniLAMo

Заменяй только одноимённые файлы в корне проекта.

В архиве:
- hedgehog_brain.py — мозг, память и характер ёжика
- hedgehog.js — микрофон, распознавание речи и поведение в браузере
- hedgehog.css — комната и анимации
- schemas.py — модели API-запросов ёжика
- server.py — API /hedgehog и /hedgehog/activity
- index.html — подключение комнаты и файлов ёжика

ВАЖНО: текущая версия озвучивает ёжика через browser speechSynthesis.
Google Cloud Text-to-Speech для ёжика в этих файлах ещё не подключён.
Следующим шагом можно отдельно подключить Google Cloud TTS.
